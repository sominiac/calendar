## Calendar

Проект с обычной реализацией календаря на `react`. Является микро-фронтед частью [репозитория](https://github.com/sominiac/main-project).

Для реализации микро-фронтенда используется пакет `module-federation/vite`.
На данном этапе реализованно только подключение к основному проекту.
Планируется добавить реализацию календаря.
